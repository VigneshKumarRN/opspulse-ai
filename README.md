\# OpsPulse AI



Agentic log-triage assistant for enterprise job failures.

Ingests execution logs, retrieves similar past incidents (RAG), and diagnoses root cause with an LLM agent.



\*\*Stack (in progress):\*\* Python · SQLite · ChromaDB · LangGraph · FastAPI · React · Docker
